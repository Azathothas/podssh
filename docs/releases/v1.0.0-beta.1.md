# podssh v1.0.0-beta.1

The first beta since this repository's history was replaced: it carries
each change since 2026-10-08. A beta is a prerelease. Its tag never moves:
a defect found in it goes into the next beta.

## The files

| File | For |
| --- | --- |
| `podssh-x86_64-unknown-linux-musl` | Linux on x86-64, static: no library and no loader needed |
| `podssh-aarch64-unknown-linux-musl` | Linux on aarch64, static |
| `podssh-x86_64-pc-windows-msvc.exe` | Windows on x86-64, with a static C runtime |
| `SHA256SUMS` | The SHA-256 of each binary |
| `THIRD-PARTY-LICENSES.md` | The licenses of the crates in the binaries, with their texts |

## Check a download

```sh
T=v1.0.0-beta.1; B=podssh-x86_64-unknown-linux-musl   # or podssh-aarch64-unknown-linux-musl
curl -fsSLO "https://github.com/Azathothas/podssh/releases/download/$T/$B"
curl -fsSLO "https://github.com/Azathothas/podssh/releases/download/$T/SHA256SUMS"
grep " $B\$" SHA256SUMS | sha256sum -c - && chmod +x "$B"
./"$B" --version   # podssh 1.0.0-beta.1
./"$B" doctor      # what this host allows, and whether the whole path works
```

On Windows, compare `(Get-FileHash podssh-x86_64-pc-windows-msvc.exe).Hash`
with its line in `SHA256SUMS` (the case of the letters differs).

## What works

`podssh ssh`, `each`, `containers`, `proxy`, `pipe`, `cp`, `mv`, `scp`,
`sftp` and `edit`, `doctor`, `keygen`, `agent`, `man`, `status`, `ping`,
`health`, `node`, `operator`, `relay`, `chat`, `play` and `config`, and
`mcp`. `podssh man` is the reference: each command, flag, `-o` keyword,
variable, file and exit code. These binaries have no Tailscale and no iroh
road: `podssh ts`, and a destination `iroh:TICKET` or `--iroh-ticket`, exit
with 70 and say so.

## What to test again

What the earlier betas asked for, and this beta has:

- `ssh_config`, `-F`, `-G` and `Match` (#14, #22).
- A relay session that drops: the hop that broke is named, and a forward is
  tried again when that is safe (#17).
- Copies (#21): `podssh cp` continues after a drop, writes a temporary
  name, checks the digest and then renames; pipelined SFTP, parallel chunks,
  delta copies, `-r`, `--delete`, `--dry-run`, progress and a bandwidth
  limit; `scp` and `sftp` with OpenSSH's command lines; `edit`; ZMODEM.
- Output for machines: `doctor --json`, `man --json`, `status`, `ping`,
  `health`, and the exit status of a remote command (#23).
- Many hosts: `each`, broadcast with an emergency stop, recordings and
  `play` (#24).
- Streams that are not SSH: `pipe`, `-W`, AF_UNIX streams, UDP over the
  relay (#26).
- `podssh doctor` in your sandbox, with and without `HTTPS_PROXY`; a
  `no_proxy` with blocks such as `10.0.0.0/8` keeps each address inside
  them off the proxy now, and `doctor` names the entry (T-316).

## What a beta does not have yet

- Build provenance and signed checksums (T-210, T-211): `SHA256SUMS` comes
  from the run that built the binaries, and is not signed.
- macOS, Linux armv7 and riscv64, and Windows aarch64 binaries (T-218).
- The check of a release from end to end with no human (T-251); it runs
  before `v1.0.0`.
- Known, for the next beta: a proxy that answers `200` to CONNECT and then
  carries no SSH is not named as the cause (T-317).

## Report a defect

Open an issue at <https://github.com/Azathothas/podssh/issues> with the
output of `podssh --version` and `podssh doctor --json`. Read that output
before you post it: it names this host's proxy and addresses, and never a
token or a password.
