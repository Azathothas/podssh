# Release notes

One file for each tag: `vX.Y.Z.md`, or `vX.Y.Z-beta.N.md` for a beta. The
release workflow fails without the file of its tag
([development.md](../development.md), section "Release builds"). The betas
`v1.0.0-beta.N` are prereleases (the operator, 2026-10-30); `v1.0.0` is the
final release, at the end of the work (T-250).
