# The result that each check of the interop harnesses must give (T-199).
# `cargo todo interop` reads the ids of the scripts and compares them with
# this file; with `--logs`, it scores a run's lines against it. Change it in
# the commit that adds, removes or renames a check.
#
#   support FILE                   a file of helpers, which prints no id
#   harness PREFIX RUN FLOOR FILE  the ids PREFIX.* of FILE, in the log RUN.log;
#                                  a run passes FLOOR of them at least
#   ID pass                        the check must print ok
#   ID env-allowed REASON          ok, or env when the host lacks REASON
support scripts/interop-lib.sh
support scripts/interop-conpty-msys2.py
